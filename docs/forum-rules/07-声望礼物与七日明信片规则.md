# 每日声望礼物与七日明信片规则

## 一、每日声望礼物

### 1. 基本规则

- 每位成员按北京时间每天只能送出 **1 次**声望礼物。
- 一次礼物为收礼者增加 `2` 点声望。
- 只能送给自己已经关注的成员，包括管理员。
- 不能送给自己，也不能送给已封禁账号。
- 收礼者会收到通知。
- 当天的赠送机会一旦成功使用，不能撤回或改送他人，次日恢复。

### 2. 使用原则

声望礼物适合表达对某位成员近期分享、帮助或长期贡献的感谢，不应成为交换工具。

以下行为属于滥用：

- 约定每天互送，长期人为抬高双方声望；
- 以送礼交换点赞、评论、邀请码或现实利益；
- 使用多个账号轮流送给同一人；
- 组织群体集中给某人送礼以操纵排行榜。

管理员可以撤回通过滥用获得的声望，并按情况处理相关账号。

## 二、七日明信片

### 1. 明信片额度

明信片按北京时间的自然月计算额度，额度取决于发送者当前声望：

| 当前声望 | 每月可寄数量 |
|---|---:|
| `0–49` | 1 张 |
| `50–349` | 2 张 |
| `350–1399` | 3 张 |
| `1400+` | 5 张 |
| 管理员 | 5 张 |

- 未使用额度不结转到下个月。
- 声望在月内上升并跨过档位后，可用上限会按新档位增加。
- 声望下降后，额度按当前档位计算；已经寄出的明信片不会撤回，但可能暂时没有剩余额度。
- 系统只在明信片成功寄出后扣除额度，重复点击不会重复寄送。

### 2. 寄送规则

- 可以寄给任意未封禁的其他成员，不要求双方互相关注。
- 不能寄给自己。
- 正文最多 500 个字符。
- 可以选择纸张主题和自定义 Emoji 邮戳。
- 寄出后不能修改、撤回或更换收件人，请在发送前确认。
- 收件人会收到一条明信片通知。

### 3. 拆阅与有效期

- 未拆阅的明信片正文不会提前发送到收件人的浏览器页面。
- 只有收件人完成拆阅操作后，系统才返回并展示正文。
- 明信片从寄出时开始保留 7 个完整的 24 小时。
- 到期后，明信片会从活动数据库中物理删除，相关旧通知也会清理。
- 删除后不能恢复。重要内容请通过适合长期保存的方式另行记录。

### 4. 内容与隐私

明信片适合感谢、祝福、简短分享和相对私密但不敏感的校园交流。

不得用于：

- 骚扰、辱骂、威胁、性暗示或在被拒绝后继续联系；
- 发送密码、验证码、证件信息、支付信息或其他高度敏感资料；
- 诈骗、交易收款、广告、拉群和传播危险链接；
- 规避公开内容审核，发送论坛禁止的内容；
- 冒充匿名或无法追溯的通信方式伤害他人。

明信片只向收件人展示正文，但不属于端到端加密通信。为处理严重违规、安全事件或依法配合必要调查，平台管理者可能在必要范围内核查相关记录。

## 三、收到不适当礼物或明信片怎么办

1. 不继续争吵或回寄攻击性内容。
2. 在明信片过期前保存必要证据和发送者信息。
3. 取消关注并在问题反馈板块提交情况。
4. 涉及威胁、欺凌或现实安全时，立即联系可信任的老师、家长或学校相关人员。
