# 违规处理、申诉与管理规则

## 一、处理目标

管理的首要目标是停止伤害、保护成员和恢复正常讨论，而不是追求公开羞辱或“赢得争论”。相似事件可能因影响范围、主观恶意、是否重复和是否主动纠正而采用不同处理方式。

## 二、常见处理措施

管理员可以根据情况采取一种或多种措施：

1. 提醒成员停止行为或修改资料；
2. 删除帖子、评论、图片、状态或其他不当内容；
3. 取消帖子置顶并撤回对应奖励；
4. 调整因错误、刷分或违规获得的声望；
5. 封禁账号，使其无法继续正常使用论坛功能；
6. 对现实安全风险或涉嫌违法的严重情况，向学校相关人员或依法有权处理的部门报告。

论坛当前没有对外承诺固定时长的“临时禁言”制度。管理员会依据事件性质选择内容处理、声望调整或账号封禁。

## 三、从轻与从重因素

### 可以从轻考虑的情况

- 初次发生、影响较小，并在提醒后立即停止；
- 主动删除或纠正错误信息；
- 主动说明系统漏洞，没有继续利用或接触他人数据；
- 能够诚实配合核查并减少后续影响。

### 可能从重处理的情况

- 重复违规或被提醒后继续；
- 使用匿名、明信片、多账号或他人账号规避管理；
- 针对特定成员持续骚扰、威胁或公开隐私；
- 组织多人围攻、刷分、操纵排行榜或批量注册；
- 伪造证据、删除关键记录后继续否认，或报复举报人；
- 涉及诈骗、危险行为、严重色情内容、现实人身安全或违法风险。

## 四、声望与封禁

- 封禁账号时，系统扣除 50 点声望。
- 解封时，系统恢复 50 点声望；这用于抵消系统封禁扣分，不代表违规记录被认定不存在。
- 普通成员声望不会长期低于 0。
- 管理员可以针对误发奖励、系统错误或刷分进行额外增减调整。
- 被封禁账号不参加普通成员排行榜，也不能正常使用关注、发帖等功能。

## 五、如何提交举报或申诉

请在“问题反馈”板块新建一篇内容清晰的帖子，尽量包含：

- 涉及的帖子、评论、账号或页面链接；
- 事件发生的大致时间；
- 对规则影响的简要说明；
- 必要且经过隐私遮挡的截图；
- 希望管理员核查或修正的具体事项。

不要在举报帖中重新公开传播敏感内容。涉及个人隐私时，可以先提供最少信息，等待管理员进一步核对。

## 六、申诉规则

- 当事人可以对内容删除、声望调整或账号处理提出一次完整申诉。
- 申诉应说明事实、可能存在的误解和希望复核的结论，而不是只表达不满。
- 重复发布相同申诉、攻击管理员或号召他人施压，不会提高处理优先级，并可能构成新的违规。
- 经复核确认处理有误时，管理员可以修正声望、解除封禁或作出说明。
- 已经从数据库或外部图床删除的内容可能无法恢复，即使申诉成立也不保证原样找回。

## 七、恶意举报

- 善意举报即使最后未认定违规，也不会因此受罚。
- 明知内容不存在问题，仍伪造材料、反复举报或借举报骚扰他人的，属于滥用管理机制。
- 不得公开举报人身份、威胁举报人或以现实关系施压。

## 八、管理员行为边界

- 管理员应只在管理、安全和技术维护所需范围内使用权限。
- 管理员不应利用后台信息满足私人好奇、传播成员隐私或帮助任何一方进行现实报复。
- 管理员账号发布的个人观点不自动成为学校立场；只有明确以公告形式发布的内容才作为论坛正式通知。
- 对管理员行为有异议，同样可以通过问题反馈提交复核。

## 九、紧急情况

出现现实人身威胁、自伤风险、严重欺凌、失联、诈骗正在发生或其他紧急事件时，不要等待论坛处理。请立即联系可信任的老师、家长、学校值班人员或相应紧急服务，同时保留必要证据。
