## 发布说明

- 建议将总则置顶，并在总则末尾附上各分则链接。
- 分则中的数值均按当前论坛实际功能编写。
- 如果以后调整声望数值、明信片额度或邀请码制度，应同时修改对应分则和版本日期。
- 公告中的“管理员”指论坛后台标记为管理员的账号，不等同于所有学校教职员工。
- 生效日期：2026 年 7 月 29 日。
