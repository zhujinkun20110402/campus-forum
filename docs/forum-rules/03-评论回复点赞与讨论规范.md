# 评论、回复、点赞与讨论规范

> 评论区采用类似群聊的展示方式，但它仍是公开讨论空间。每一句回复都应围绕内容，而不是围攻某个人。

## 一、评论与回复

- 所有帖子都支持评论，也支持回复任意一条已有评论。
- 回复某条评论时，系统会引用被回复者和原评论摘要，并向对方发送通知。
- 直接评论帖子时，帖子作者会收到通知；回复自己或评论自己的帖子时，不重复给自己发送通知。
- 单条评论最多 5000 个字符。
- 回复引用只代表回复对象，不代表认可其观点。

## 二、良好讨论的基本方式

- 先说明你回应的是哪一点，再给出理由、事实或个人经验。
- 区分“我不赞同这个观点”和“这个人不行”。前者是讨论，后者容易变成人身攻击。
- 对信息不完整的帖子，可以先提问，不急于给当事人下结论。
- 纠正错误时尽量提供可靠来源，不用讽刺代替解释。
- 发现讨论已经偏离主题，可以另开新帖，而不是让原评论区无限争吵。

## 三、点赞规则

- 点赞表示你认可、感谢或认为内容值得被更多人看到。
- 给他人的帖子点赞，帖子作者获得 3 点声望；取消点赞时，这 3 点会同步撤回。
- 给自己的帖子点赞不会增加声望。
- 点赞会向帖子作者发送通知；取消点赞后，对应通知会删除。
- 禁止约定互赞、使用多个账号点赞或集中操作排行榜。

## 四、评论声望

- 每成功发布一条评论，评论者获得 2 点声望。
- 删除评论会扣除 2 点声望。
- 为声望重复发送“顶”“同意”等无实际内容的评论，可能被删除；情节明显时，管理员可以额外调整声望。
- 声望奖励鼓励有价值的参与，不代表评论内容获得管理员认可。

## 五、不得出现的评论行为

- 辱骂、阴阳怪气、人身攻击、威胁或歧视；
- 连续追问私人信息，逼迫当事人回应；
- 断章取义地引用他人内容，煽动更多人围攻；
- 重复粘贴同一段话、发送无意义字符或刷表情；
- 故意把无关争议带到多个帖子评论区；
- 公开他人的聊天记录、联系方式、账号或现实身份；
- 通过回复发送诈骗、广告、钓鱼链接或不当内容。

## 六、删除权限与影响

- 评论作者可以删除自己的评论。
- 管理员可以删除违反规则的评论。
- 删除评论会同时影响相关引用和通知，部分回复可能继续存在，但原引用可能显示为已删除或不再完整。
- 删除操作不保证能够恢复。

## 七、遇到冲突时怎么做

1. 停止继续升级语气，不要跨帖子追击。
2. 保留必要链接和截图，但不要二次公开传播伤害性内容。
3. 在问题反馈板块提交情况，说明帖子、评论和大致时间。
4. 涉及现实安全、欺凌或威胁时，优先联系可信任的老师、家长或学校相关人员。
