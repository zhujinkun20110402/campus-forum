# 发帖、分区与内容规范

> 好帖子不一定很长，但应当让读者看得懂主题、分得清事实与观点，并知道应该如何回应。

## 一、发帖基本要求

- 标题应直接说明主题，不使用与正文无关的夸张标题。
- 标题最多 200 个字符；正文不能为空，支持 Markdown 和图片。
- 发布前选择最准确的分类。部分分类可以存在但不显示在首页导航中，以发帖页面实际选项为准。
- 同一件事情原则上只发一篇。需要补充信息时，可以在评论中更新；问题已经解决且不再需要保留时，可以删除原帖。
- 转发通知、文章、图片或资料时，应注明来源；不能确认真实性时，应明确写明“待核实”。

## 二、主要分区规则

### 1. 校园公告

- 仅管理员可以发布。
- 用于论坛规则、系统维护、活动提示和需要集中告知的校园信息。
- 普通成员发现重要信息，可以在问题反馈中提交，由管理员核实后决定是否发布公告。

### 2. 学习交流

- 可发布学习方法、资料分享、题目讨论、课程经验和学习搭子需求。
- 提问时尽量写明年级范围、学科、已尝试的方法和具体疑问。
- 禁止发布考试泄题、作弊方法、代写作业、付费代考或盗版付费资料。
- 分享答案时应鼓励理解过程，不以嘲讽成绩或基础较弱的同学为乐。

### 3. 失物招领

- 标题建议写明“寻物”或“招领”、物品类型和大致地点。
- 正文说明时间、地点、外观特征和认领方式，但应保留一项关键特征用于核验。
- 证件、校园卡、钥匙等物品的照片应遮挡姓名、编号、条形码和其他敏感信息。
- 不建议公开手机号、住址等信息。
- 物品找回后，可在评论中说明结果；不再需要展示时可以删除帖子。
- 冒领、索要报酬、借机获取个人信息会被从严处理。

### 4. 校园活动

- 写明活动名称、时间、地点、对象、报名方式和主办方。
- 不得冒充学校或社团发布活动，不得把非官方活动包装成强制参加。
- 涉及收费、校外地点、夜间活动或安全风险时，必须清晰说明，不得隐瞒。
- 活动取消或信息改变后，应及时在评论中补充。

### 5. 二手交易

- 写明物品实际状态、价格、缺陷、是否有配件以及交付方式。
- 不得出售违禁品、危险品、药品、烟酒、账号、考试资料、来历不明物品或侵犯版权的复制品。
- 不进行虚假描述、恶意抬价、定金诈骗或诱导到不明平台交易。
- 论坛只提供信息展示，不提供担保、托管和退款仲裁。交易前请核验物品，尽量选择安全的校内公共场所当面完成。
- 交易完成后可在评论中标注“已出”，不再需要展示时可以删除帖子。

### 6. 表白墙

- 页面会对普通成员隐藏作者身份，但系统仍保留发布账号。
- 可以表达喜欢、感谢、遗憾和真诚心声，不得借匿名辱骂、造谣、性骚扰、逼迫回应或公布他人隐私。
- 不写能够让他人被轻易锁定并因此受到困扰的敏感细节。
- 不得连续发布针对同一人的内容，尤其是在对方已经表达拒绝或不适之后。
- 表白内容最多 2000 个字符。

### 7. 问题反馈

- 用于报告论坛故障、界面问题、内容治理问题和功能建议。
- 报告故障时建议写明设备、浏览器、操作步骤、预期结果和实际结果。
- 截图前遮挡密码、邮箱、邀请码、Cookie、令牌和他人的私人信息。
- 发现安全漏洞时只说明影响和复现所需的最少信息，不公开利用代码或他人数据。
- 反馈板块不是攻击管理员或重复催促的场所。同一问题请集中在一篇帖子中更新。

## 三、图片与链接

- 图片必须与正文相关，并确保自己有权发布。
- 发布含有人脸、聊天记录、作业、成绩或个人资料的图片前，应取得同意并做好遮挡。
- 不发布二维码诱导转账、钓鱼网站、不明安装包或可能危害设备的链接。
- 外部链接的内容同样受论坛规则约束；用链接绕过禁止内容仍视为违规。

## 四、禁止的发帖方式

- 重复刷屏、无意义灌水、只为获得声望而拆分内容；
- 标题与正文严重不符，或故意制造恐慌、冲突和误解；
- 未经核实点名指控某位成员违法、作弊、欺凌或有其他严重问题；
- 发布他人隐私、偷拍内容或带有羞辱目的的图片；
- 商业广告、拉群营销、诱导关注、刷单兼职和不明募捐；
- 使用大量复制内容、机器生成内容或无关关键词占据搜索结果。

## 五、删除与编辑提示

- 帖子作者和管理员可以删除帖子。
- 当前删除操作不可保证恢复，请在删除前确认。
- 删除帖子会扣除发帖时的基础声望，详细数值见《声望等级、成就与排行榜规则》。
- 管理员可以置顶有价值的帖子，也可以在内容不再适合置顶时取消置顶。
