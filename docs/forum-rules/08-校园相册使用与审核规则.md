# 校园相册使用与审核规则

> 校园相册用于保存值得共同记住的校园画面，不是私人网盘，也不是未经同意公开他人照片的场所。

## 一、上传与审核

- 已登录成员可以上传照片，并可填写简短备注。
- 支持常见的 JPG、PNG 和 WebP 图片，可一次选择多张。
- 普通成员上传后进入待审核区，管理员审核通过后才会出现在公开照片墙。
- 管理员上传的照片可以直接进入公开相册。
- 管理员可以批准、拒绝或删除照片。
- 审核等待时间不作固定承诺，请勿为同一张照片反复上传。

## 二、适合上传的内容

- 校园风景、建筑、季节变化和公开环境；
- 经参与者同意的活动、社团、比赛和集体记录；
- 校园作品、布置、展览和有纪念意义的物品；
- 其他积极、真实且适合校园公开展示的画面。

## 三、人物照片与肖像

- 清晰可辨认的人物是照片主体时，上传前应获得本人同意。
- 集体活动照片也应避免让个别成员处于尴尬、受伤、被处罚或其他不适合公开的状态。
- 不上传偷拍、更衣、就医、休息、冲突现场等具有明显私密性的画面。
- 当事人要求撤下涉及自己的照片时，管理员会结合身份核验和实际情况处理。
- 不使用侮辱性备注、恶意裁剪、变形或合成图片嘲笑他人。

## 四、敏感信息

上传前请检查并遮挡：

- 学生证、身份证、校园卡、准考证和带编号的证件；
- 成绩单、花名册、座位表、联系方式和家庭住址；
- 电脑屏幕上的账号、Cookie、二维码和内部系统信息；
- 能够暴露个人固定行程、门禁方式或安全设施细节的信息。

图片可能包含拍摄时间和位置信息。论坛不保证自动清除所有元数据，介意时请在上传前自行移除。

## 五、版权与真实性

- 原则上只上传自己拍摄、创作或已经获得授权的图片。
- 转发他人作品时，应取得许可并在备注中标明来源。
- 不上传盗版摄影作品、带明显版权争议的素材或去除水印后的图片。
- 对经过明显合成、生成或大幅修改的图片，应在备注中说明，不能把它作为真实事件照片传播。

## 六、禁止内容

- 色情、暴力、血腥、危险行为或其他不适合校园展示的图片；
- 用于挂人、羞辱、造谣或暴露他人隐私的图片；
- 广告、收款码、钓鱼二维码、群聊推广和交易引流；
- 与校园无关的大量表情包、截图和重复图片；
- 违法内容、违禁品以及可能危害校园安全的信息。

## 七、删除与保存

- 公开相册由管理员统一维护和删除。
- 相册不承诺永久保存，图片可能因审核、权利请求、存储维护或技术故障被移除。
- 请自行保留原图，不要把论坛相册作为唯一备份。
- 相册上传目前不发放声望，不应通过重复上传获取关注或占据版面。
