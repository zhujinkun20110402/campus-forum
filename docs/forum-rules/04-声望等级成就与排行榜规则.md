# 声望、等级、成就与排行榜规则

> 声望用于记录长期、真实、有帮助的社区参与。它不是成绩，也不代表一个人的现实价值。

## 一、声望如何增加或减少

| 行为 | 声望变化 | 说明 |
|---|---:|---|
| 发布帖子 | `+5` | 每篇成功发布的普通帖子或匿名表白 |
| 当日首次发帖 | 额外 `+3` | 与基础发帖奖励叠加，即当日首帖共 `+8` |
| 发布评论 | `+2` | 每条成功发布的评论或回复 |
| 帖子被他人点赞 | `+3` | 自己给自己点赞不增加声望 |
| 每日签到 | `+1` | 按北京时间每天一次 |
| 收到每日声望礼物 | `+2` | 由关注你的成员赠送 |
| 帖子被管理员置顶 | `+20` | 取消置顶时同步撤回 `20` 点 |
| 删除帖子 | `-5` | 作者删除或管理员删除都会作用于原作者 |
| 删除评论 | `-2` | 作者删除或管理员删除都会作用于原作者 |
| 取消点赞 | 作者 `-3` | 撤回该次点赞带来的奖励 |
| 账号被封禁 | `-50` | 解封时系统恢复 `50` 点 |
| 管理员调整 | 视情况而定 | 用于纠错、撤回不当收益或处理违规 |

普通成员声望最低显示为 0，不会因为扣分长期显示负数。

## 二、等级划分

| 等级 | 称号 | 声望范围 |
|---|---|---:|
| Lv.1 | 萌新 | `0–49` |
| Lv.2 | 学徒 | `50–149` |
| Lv.3 | 活跃 | `150–349` |
| Lv.4 | 贡献者 | `350–699` |
| Lv.5 | 达人 | `700–1399` |
| Lv.6 | 大佬 | `1400–2999` |
| Lv.7 | 传奇 | `3000–5999` |
| Lv.8 | 至尊 | `6000+` |

管理员显示专属等级“校园守护者”和固定展示声望 `9999`，但不参加普通成员排行榜竞争。

## 三、排行榜规则

- 排行榜按普通成员当前声望从高到低排列。
- 管理员和已封禁账号不进入普通成员排行榜。
- 声望相同的情况下，注册时间更早的成员优先；仍相同则由系统稳定排序。
- 当前第一名会获得专属皇冠和主页视觉效果。
- 取消点赞、删除内容、取消置顶和管理调整都可能使排名实时变化。
- 排行榜是社区参与记录，不得用它组织拉票、互赞或攻击其他成员。

## 四、当前成就

| 成就 | 获得条件 |
|---|---|
| 初出茅庐 | 发布第一篇帖子 |
| 校园引路人 | 自己创建的邀请码成功邀请至少 1 位新成员 |
| 七日留名 | 累计签到达到 7 天，不要求连续 |
| 话唠 | 累计发布至少 50 条评论 |
| 人气王 | 发布的帖子累计收到至少 100 个点赞 |
| 勤奋作者 | 累计发布至少 20 篇帖子 |
| 社交达人 | 至少发布 5 篇帖子，并累计参与至少 25 条评论 |
| 置顶达人 | 至少有一篇帖子被管理员置顶 |
| 校园守护者 | 管理员专属成就 |

成就根据当前可统计数据自动计算。删除帖子、评论或取消点赞后，如果不再满足条件，部分成就可能不再显示。

## 五、反刷分规则

以下行为会被视为操纵声望：

- 用无意义帖子或评论重复获取基础奖励；
- 多账号互赞、自赞、轮流送礼或人为控制排行榜；
- 先大量互动获取声望，再集中删除内容；
- 以邀请码、礼物、明信片或其他利益交换点赞和评论；
- 使用脚本、自动点击工具或接口批量操作。

管理员可以删除相关内容、撤回不当声望、追加调整或封禁账号。即使系统暂时发放了奖励，也不代表刷分行为被允许。

## 六、常见问题

### 为什么点赞数没变，但声望变了？

可能是其他帖子被点赞或取消点赞、帖子置顶状态改变、内容被删除，或管理员进行了纠错调整。

### 删除帖子为什么要扣 5 点？

发布时系统已经发放 5 点基础奖励。删除时扣除对应基础奖励，避免通过反复发布和删除累计声望。

### 每日首次发帖的额外奖励能重复获得吗？

不能。同一个系统日内只有第一篇成功发布的帖子获得额外 3 点。

### 管理员的 9999 声望是真实积分吗？

不是普通成员排行榜中的竞争积分，而是管理员身份的固定展示值。
